# 💰 Expense Tracker

A simple Python-based Expense Tracker that allows users to record their expenses, save them to a CSV file, and summarize their spending.

This project was built as a learning project to practice **Python functions, file handling, CSV operations, and basic data processing**.

## 🚀 Features

* Add and record expenses
* Store expenses in a CSV file
* Categorize expenses
* View expense information
* Calculate and summarize total spending
* Simple command-line interface

## 🛠️ Technologies Used

* **Python**
* **CSV**
* **File Handling**
* **Python Functions**

## 📁 Project Structure

```text
Expense Tracker/

```

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/gauravyadavcodes/expense-tracker.git
```

### 2. Open the project folder

```bash
cd expense-tracker
```

### 3. Run the application

```bash
python expense_tracker.py
```
